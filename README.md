# LAVAKIDS — paquete móvil

Esta es la versión consolidada de LAVAKIDS, preparada como PWA instalable.

## Instalación
La carpeta debe publicarse en HTTPS. Desde el móvil:
- Android/Chrome: menú → Instalar aplicación.
- iPhone/Safari: Compartir → Añadir a pantalla de inicio.

La aplicación conserva los datos localmente en el dispositivo.
